# 승인된 화면 시안

사장님이 승인한 화면 시안의 원본입니다. Flutter 화면은 이 시안과 같아야 합니다. 다르면 시안이 기준입니다.

- 파일 하나가 화면 하나입니다. `<svg>` 의 경로, 크기, 선 굵기, 둥글기, 글자 크기를 그대로 옮깁니다.
- 색은 각 파일의 `PALETTES` 가 `design/tokens.json` 과 같은 값입니다. 화면 코드에는 토큰 이름으로 씁니다.
- 아이콘은 전부 선 아이콘입니다. 이모지와 Material 기본 아이콘을 쓰지 않습니다. 기분 얼굴도 선으로 그린 아이콘이고 색은 기분마다 하나입니다.
- `{{…}}` 는 시안 도구의 자리표시입니다. 값은 같은 파일 아래쪽 `<script>` 에 있습니다.
