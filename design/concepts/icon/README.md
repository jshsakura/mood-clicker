# 앱 아이콘 시안

확인일: 2026-11-18

13절 규격에 맞춰 제작한 두 가지 방향(A, B)의 앱 아이콘 시안입니다. 두 방향 모두 안드로이드 적응형 아이콘의 배경(`adaptive_icon_background`)은 단색 **`#FFFFFF`** 를 사용하므로 별도 배경 PNG 는 두지 않습니다.

---

## 1. 파일 목록

| 방향 | 파일 | 해상도 / 형식 | 비고 |
|---|---|---|---|
| **A (둥근 얼굴)** | `a/ios-1024.png` | `1024x1024` RGB PNG (알파 없음) | `#FFFFFF` 바탕 위 둥근 돌 얼굴(`#ECECF0`)과 감은 눈(`#383840`) |
| **A (둥근 얼굴)** | `a/foreground.png` | `432x432` RGBA PNG (투명 배경) | `108dp@4x`, 중앙 `66dp`(`264px`) 안전 영역 안에 얼굴 배치 |

## 2. 제작 도구·프롬프트(파라미터) 및 상업 이용 가능 여부

- **제작 도구**: Python + Pillow (4배 슈퍼샘플링 렌더링 후 LANCZOS 축소)
- **방향 A 파라미터**: `char-geo-idle` 시안의 둥근 돌 머리 비율을 따와 외곽선(`#D4D4DC`)과 굵은 감은 눈 두 줄(`#383840`)만 남겨 `48px` 에서도 흐려지지 않게 설계했습니다.
- **방향 B 파라미터**: 저장소의 `assets/fonts/Baloo2-ExtraBold.ttf` 로 `M`(`#16161A`)을 렌더링하고 우측 하단에 토큰 `light.happy` 색상(`#F2A900`) 원을 배치했습니다.
- **상업 이용 가능 여부**:
  - 모든 아이콘 이미지는 저장소 내 스크립트로 직접 생성한 결과물이며, 사용한 `Baloo 2` 글꼴은 **SIL Open Font License (OFL)** 로 상업 이용 및 앱 번들 재배포가 가능합니다.
