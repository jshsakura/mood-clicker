## 1. 수집·처리하는 항목과 수집하지 않는 항목

### 1.1 수집·처리하는 항목
- **1단계 (내 기록, 기기 안 저장)**: 모든 기록은 기기 안의 파일 두 개와 시스템 설정 저장소에만 저장됩니다.
  - `<앱 보관함>/journal.json` (앱이 직접 쓰는 JSON 파일): 사용자가 직접 고른 **기분 종류**와 **두드린 횟수**, **마지막 두드림 시각과 차례**, 그날 남긴 **한마디**(고른 준비 문장 아이디 또는 직접 쓴 짧은 글), 날짜.
  - `<앱 보관함>/cheer_decks.json`: 이미 보여 준 **응원 문구의 위치** 값. 문구 내용이 아니라 몇 번째까지 냈는지만 저장합니다.
  - 시스템 설정 저장소(안드로이드 SharedPreferences, iOS NSUserDefaults): **테마, 언어, 진동 켜기와 세기, 소리와 소리 묶음, 응원 문구와 글자 크기, 가득 찰 때 화면 흔들기, 기울여 쏟기, 저녁 알림과 시각, 지도 보내기 선택(기본 꺼짐)**.
- **3단계 (내 주변 지도, 선택 참여 시 서버 전송)**:
  - 설정에서 **"지도에 내 기분 보태기"** 를 직접 켠 사용자에 한해, **기분 종류**, **두드린 횟수**, **날짜**, 그리고 기기에서 변환한 **동네 크기 격자 번호(Uber H3 해상도 7, 약 5km²)** 만 서버로 전송합니다.
  - 지도 참여는 3단계에서 **계정과 함께** 도입하는 기능입니다. 현재 파일럿(1단계)은 어떤 데이터도 기기 밖으로 보내지 않습니다.
  - 익명 중복 집계를 위해 서버가 발급하는 **익명 계정 식별자**(예: 익명 인증 UUID)를 함께 사용합니다.

### 1.2 수집하지 않는 항목
- **정확한 위치(원본 GPS 위도·경도 좌표)** 는 기기 밖(서버)으로 전송하거나 저장하지 않습니다.
- **이름, 닉네임, 이메일 주소, 전화번호** 등 실명·연락처 정보를 수집하지 않습니다.
- **광고 식별자(IDFA, AAID)** 를 수집하거나 추적에 사용하지 않습니다.

## 2. 기기 안 저장과 서버 전송의 구분

| 구분 | 저장 위치 | 전송 여부 | 설명 |
|---|---|---|---|
| **내 기록 (1~5번 화면)** | 사용자 기기 내부 (`journal.json` 등 JSON 파일과 시스템 설정 저장소) | 전송 안 함 | 앱을 지우거나 기기 내 초기화를 누르기 전까지 기기 안에만 남습니다. |
| **내 주변 지도 보기** | 서버 집계 조회 | 기분 미전송 | 지도를 볼 때도 "내 기분 보태기" 가 꺼져 있으면 내 기분을 서버에 보내지 않습니다. |
| **내 주변 지도 참여** | 익명 집계 서버 (예: Supabase) | 선택 시 전송 | 사용자가 직접 켠 경우에만 H3 해상도 7 격자 번호와 오늘 기분·횟수를 보냅니다. 한 격자에 그날 참여한 사람이 **최소 5명 미만**이면 지도에 표시하지 않습니다. |

### 2.1 운영체제 백업에 포함됩니다

앱 데이터는 기기의 운영체제 백업에 함께 저장될 수 있습니다. 안드로이드에서는 자동 백업과 기기 이전(앱이 별도의 백업 배제 규칙을 두지 않았습니다), 아이폰·아이패드에서는 iCloud 기기 백업과 컴퓨터 백업입니다. 백업 데이터는 사용자의 운영체제 계정과 화면 잠금이 지키며, 이 앱이 직접 읽거나 보낼 수 없습니다. 기록을 잃지 않는 길을 남겨 두려고 백업을 끄지 않기로 했습니다.

## 3. 익명 계정

- 익명 계정은 3단계 지도 참여와 함께 도입합니다. 현재 파일럿(1단계)에는 계정이 없습니다.
- 본 앱은 회원가입이나 이메일 로그인 없이 **익명 계정(Anonymous Auth)** 방식으로 동작합니다.
- 익명 계정 식별자는 같은 기기에서 같은 날 여러 번 보낸 기분 집계를 합산·갱신하는 용도로만 쓰며, 개인의 신원(이름·연락처 등)과 연결하지 않습니다.

## 4. 처리 목적, 보관 기간 및 삭제·파기 방법

- **처리 목적**: 개인 기분 기록 및 달력·회고 제공(기기 내), 동네 단위 익명 기분 합계 시각화(3단계 지도 참여 시).
- **보관 기간**:
  - **기기 내 데이터**: 사용자가 삭제하거나 앱을 제거할 때까지 보관합니다.
  - **서버 익명 집계 데이터**: 일별 통계 제공 및 악용 방지 목적 달성 후 `<보관 기간, 예: 30일 또는 90일>` 이내 파기하며, 개인을 알아볼 수 있는 원본 좌표는 애초에 보관하지 않습니다.
- **삭제 및 파기 방법**:
  - **기기 내 데이터 삭제**: 앱 설정의 데이터 초기화 기능 또는 앱 삭제로 즉시 파기합니다.
  - **서버 익명 데이터 및 익명 계정 삭제**: 앱 내 `"지도 참여 끄기 / 서버 데이터 삭제"`(또는 `<문의 이메일>` 요청) 시 지체 없이 복구 불가능한 방법으로 파기합니다.
