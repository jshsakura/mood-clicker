# 무료 날씨 API 조사

확인 날짜: 2026-11-19

## 결론

- **MET Norway (`api.met.no`, Locationforecast 2.0)** 를 기본 날씨 제공자로 채택합니다.
- API 키 없이 무료로 사용할 수 있고, **CC BY 4.0** 및 노르웨이 공공데이터 라이선스(NLOD 2.0) 아래 **상업적 앱 배포가 허용**됩니다. 전 세계 좌표를 지원하므로 한국어·영어·일본어 사용자 모두에게 동작합니다.
- 필수 조건은 두 가지입니다: (1) 요청 헤더에 앱 이름과 연락처가 담긴 고유 `User-Agent` 포함, (2) 앱 내 출처 표기(`MET Norway`).

## 후보 비교

| 제공자 | API 키 | 무료 플랜 상업적 앱 허용 | 적용 범위 | 비고 |
| --- | --- | --- | --- | --- |
| **MET Norway (`api.met.no`)** | **불필요** | **허용** (CC BY 4.0 / NLOD 2.0) | 전 세계 | `User-Agent` 필수, 출처 표기 필수, `Yr` 명칭 사용 금지 |

| **기상청 단기예보 (공공데이터포털)** | **필요** (`serviceKey`) | 허용 (공공누리 제1유형) | 한국 한정 | API 키 클라이언트 보관 부담, 격자 좌표 변환 필요, 해외 미지원 |

## 약관 원문 및 근거 (2026-11-19 확인)

1. **MET Norway Weather API (`api.met.no/doc/TermsOfService`)**:
   - 라이선스 및 상업적 허용: 무료로 제공되며 CC BY 4.0 및 NLOD 2.0 조건 아래 유료 앱·광고 포함 서비스 등 상업적 목적을 포함해 자유롭게 이용할 수 있습니다.
   - 출처 표기: `"Data from MET Norway"` 또는 `"Based on data from MET Norway"` 형태로 데이터 출처를 밝혀야 합니다.
   - 식별 헤더 및 명칭 제한: 모든 요청에 앱 이름과 연락처(웹사이트 또는 이메일)를 담은 고유 `User-Agent` 헤더를 보내야 하며, 누락 시 차단될 수 있습니다. 서비스 이름에 `Yr` 을 쓰거나 MET Norway·Yr·NRK 의 공식 제휴처럼 보이게 해서는 안 됩니다.

2. **Open-Meteo (`open-meteo.com/en/terms`)**:
   - 무료 API(일 10,000건 미만)는 비상업적 용도(non-commercial use)로만 제한됩니다. 구독·광고·상업 제품·영리 활동에 해당하는 앱은 유료 상업 플랜을 계약해야 합니다.

3. **기상청 단기예보 조회서비스 (`data.go.kr`)**:
   - 공공누리 제1유형(출처표시)으로 상업적 활용이 가능하나, 발급받은 인증키(`serviceKey`)를 앱에 넣거나 중계 서버를 두어야 하며 한국 영역만 지원합니다.
