## git 과 합치기

| 일어난 일 | 규칙 | 막는 곳 |
|---|---|---|
| 떨어진 HEAD 에서 커밋해 브랜치에 남지 않았고, 합치기가 아무것도 하지 않았습니다 | 커밋 전에 `git branch --show-current` 로 브랜치 위인지 봅니다. 보고에는 커밋 해시를 적습니다 | 리뷰 |
| 두 작업자가 같은 ARB 키를 하나는 지우고 하나는 썼습니다 | ARB 충돌은 양쪽 키를 합치고 생성 파일은 다시 만듭니다. 다른 사람이 쓰는 키를 지우기 전에 전체에서 찾습니다 | `tool/l10n_check.py`, `tool/fl analyze` |
| 기분이 다른 문구 파일끼리 같은 문장이 들어갔습니다 | 기분이 달라도 같은 문장(정규화 기준)을 쓰지 않습니다 | `tool/cheers_check.py` |
| 맨 `git stash` 를 쓰면 다른 worktree 의 것을 꺼낼 수 있습니다 | 임시 커밋으로 비켜 둡니다 | `AGENTS.md` |
| 훅에 막혀 커밋이 안 됐는데 끝났다고 보고했습니다 | 보고 전에 `git log -1` 로 커밋이 있는지 봅니다 | 리뷰 |
| 테스트를 먼저 썼지만 실패하는 것(RED)을 기록하지 않았습니다 | 고치기 전에 새 테스트가 실패하는 것을 한 번 돌려 보고에 적습니다 | 리뷰 |
