기준은 `integrate/poc`의 `6783914`입니다. 기분을 고르고 두드린 뒤 달력에서 기기 안에 남은 기록을 돌아보는 파일럿입니다. 지도와 서버는 3단계에서 다룹니다.

## 역할과 작업 방식

| 역할 | 맡는 일 |
|---|---|
| 팀장·통합 | 작업을 나누고 명세를 관리하며 브랜치를 합칩니다. |
| 플랫폼·빌드 | 네이티브 설정, 시작 화면, 위젯, 빌드 환경을 맡습니다. |

## 남은 일

### 실기기 확인

- 안드로이드와 iPhone에서 앱 시작, 기분 고르기, 두드리기, 오늘의 한마디, 달력까지 한 바퀴 돕니다. 앱을 다시 열었을 때 기록이 남는지 확인합니다.
- 연타 중 진동과 소리, 가득 찰 때 반응, 기울이기와 흔들기, 시작 화면에서 앱으로 넘어가는 모습을 봅니다. iPhone은 무음 스위치를 켰을 때 소리와 진동을 따로 확인합니다.
- 위젯, 앱 아이콘 바로가기, 저녁 알림이 앱을 올바른 화면으로 여는지 확인합니다. iOS 위젯은 Xcode에서 확장 타깃을 연결하고 서명한 뒤 확인합니다. [네이티브 화면 점검](NATIVE_SURFACES.md)

### 정할 것

- **쏟을 때 두드림 유지**. 쏟는 중에도 입력을 받아 누적 횟수에 넣을지, 화면의 채움과 반응은 어떻게 보여 줄지 정합니다.
- **지도 비율 정책 (확정, 2026-11-19)**: 동네 전체 기분 비율은 보여 줍니다(사장님 결정 2026-11-19, 표시 방식은 상수로 바꿀 수 있음). 사람과 동네 순위와 '남들보다' 문구는 금지하고, 기분 보내기는 직접 켠 사람만, 5명 미만 칸은 숨깁니다. [기능 명세](SPEC.md) · [설계 원칙](PRINCIPLES.md)
- **달력 도장**. 도장 시안, 문구와 찍는 조건을 확정합니다. 글꼴과 디자이너 SVG의 비교는 조사 문서에 있습니다. [조사 15절](RESEARCH.md)
- **화남의 숨 쉬기 안내**. 두드림에서 호흡 안내로 넘어갈 시점과 건너뛰는 방법을 정합니다. [설계 근거](EVIDENCE.md)
- **웰니스와 디지털 치료제**. 파일럿은 기분 기록과 마음 관리로 안내합니다. 디지털 치료제 방향을 별도로 검토할지 정합니다. [설계 원칙](PRINCIPLES.md) · [설계 근거](EVIDENCE.md)
