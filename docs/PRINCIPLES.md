# 핵심 가치와 설계 원칙

작성 2026-11-18. 이 앱은 기분이 가라앉은 사람을 돕는 마음 관리 앱입니다. 치료 앱이 아니고, 새 기능과 새 문구는 아래 여섯 가지에 어긋나지 않는지부터 봅니다.

| 가치 | 뜻 | 하지 않는 것 |
|---|---|---|
| 응원보다 인정 | 지금 느끼는 감정이 그럴 만하다고 말해 줍니다 | "힘내", "긍정적으로 생각해", "더 힘든 사람도 있어" |
| 분출보다 진정 | 두드림은 몸을 가라앉히는 쪽으로 이어집니다 | "다 쏟아 내", "털어 내", "더 세게", 부수는 효과 |
| 잃게 하지 않기 | 한 번 남긴 기록은 줄지도 사라지지도 않습니다 | 연속 기록, 끊김 경고, 줄어드는 점수, 초기화 |
| 비교하지 않기 | 내 기분은 나와만 견줍니다. 동네 전체 기분 비율은 보여 줍니다(사장님 결정 2026-11-19, 표시 방식은 상수로 바꿀 수 있음). 기분 보내기는 직접 켠 사람만, 5명 미만 칸은 숨깁니다 | 사람과 동네 순위, "남들보다" 문구 |
| 안전하고 정직하게 | 힘들 때 갈 곳을 늘 보여 주고, 효과를 부풀리지 않습니다 | "치료", "우울증 개선", 틀린 상담 번호 |
| 모든 언어에 똑같이 | 한국어와 영어(이후 일본어)에 같은 원칙과 같은 검사를 씌웁니다 | 한국어만 검수하고 영어는 직역 |

함께 편집하는 문서(한국어, 영어 탭): 팀 공유 링크는 TEAM.md 에 둡니다.
근거와 효과 크기: [EVIDENCE.md](EVIDENCE.md). 문구 규칙 값: `tool/cheers_rules.json`.

## Core values (English)

| Value | Meaning | What we never do |
|---|---|---|
| Validate before cheering | Say the feeling makes sense | "Cheer up", "Think positive", "Others have it worse" |
| Calm, not vent | Tapping leads toward settling the body | "Let it all out", "Hit harder", smashing effects |
| Never take things away | A record never shrinks or disappears | Streaks, broken-streak warnings, decaying scores, resets |
| No comparison | Your mood is measured only against yourself. Area mood ratios are shown overall (owner decision 2026-11-19; display mode is configurable via a constant). Sharing is opt-in only, and cells with fewer than 5 people are hidden | Personal or area rankings, "than others" copy |
| Safe and honest | Help is one tap away; effects are never overstated | "Treatment", "improves depression", wrong hotline numbers |
| Same rules in every language | Korean and English (later Japanese) share values and checks | Reviewing Korean only, machine-translating English |
