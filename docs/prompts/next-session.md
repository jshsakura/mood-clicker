## 기억할 것

- 공개 저장소입니다. 실제 IP, 도메인, 이메일, 사람 이름, 홈 경로, 키를 코드, 커밋, PR 어디에도 넣지 않습니다.
- `main` 에 직접 push 하지 않습니다. push 는 `tool/test.sh && git push ...` 처럼 테스트와 한 명령으로 묶습니다.
- 디버그 키로 서명한 APK 라서, 예전에 릴리스 키로 깐 시험판 위에는 덮어 깔리지 않습니다. 지우고 새로 깝니다.
- 프롬프트 기록(이 폴더)은 세션 기록에서 뽑아 공개용으로 다듬은 것입니다. 다듬는 규칙은 [README.md](README.md) 에 있습니다.
