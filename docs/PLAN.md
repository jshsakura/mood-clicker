# 기분 클리커 계획 (가칭)

작성 2026-11-18. 이 문서는 초기 설계 계획이며, 현재 1단계 파일럿 기능(도메인, JSON 저장, 화면, 진동·소리, 설정, 알림·위젯)은 구현되었습니다. 현행 규격은 [기능 명세](SPEC.md) 를 따릅니다.

## 한 줄 정의

오늘의 기분을 고르고 연타한 횟수로 그 기분이 얼마나 컸는지 남긴다. 날짜별로 행복과 슬픔을 나눠 보여 주고,
나중에는 다른 사람들의 그날 기분을 지도로 함께 본다.

## 출시 대상과 기술

- 안드로이드, 아이폰이 본선이고 맥은 파일럿이다.
- Flutter 하나로 세 곳을 낸다.
- 안드로이드 빌드와 테스트는 이 서버의 Flutter 도커(`ghcr.io/cirruslabs/flutter:stable`, 3.44)에서 한다.
- 아이폰과 맥 빌드는 맥이 필요하다. 맥이 없으면 GitHub Actions 의 macOS 러너로 빌드한다.
- 진동 손맛은 에뮬레이터로 확인할 수 없으니 실기기에서 본다.

## 핵심 규칙

1. 기분을 하나 고른다. 기분마다 행복 쪽인지 슬픔 쪽인지가 정해져 있다.
2. 연타한다. 한 번 누를 때마다 진동과 애니메이션이 반응한다.
3. 연타 수가 그 기분의 강도가 된다.
4. 하루에 여러 번 남길 수 있다. 그날의 행복 합계와 슬픔 합계를 따로 쌓는다.

정해야 할 것:

- 기분 목록. 몇 개로 할지, 중립 기분을 둘지.
- 연타를 어떻게 끊을지. 제안은 "10초 동안 누른 만큼" 이다. 시간 제한이 없으면 오래 누른 사람이 이기는 게임이 된다.
- 손가락 여러 개로 동시에 누르는 것을 셀지.

## 데이터

```
Mood      { id, 이름, 쪽(행복|슬픔) }
Session   { 날짜, 기분, 연타 수, 시각 }
DaySummary{ 날짜, 행복 합계, 슬픔 합계 }   // Session 에서 계산한다. 따로 저장하지 않는다.
```

초기 계획에서는 SQLite 를 적었으나, 현재 파일럿은 기기 안 JSON 파일(`DayRecord` v2)로 저장한다. 지도 단계(계획)에서 서버 동기화를 붙인다.

## 화면

- 오늘: 기분 고르기, 연타 버튼, 방금 남긴 강도.
- 기록: 날짜별 행복과 슬픔 막대, 달력 보기.
- 지도: 3단계에서 추가한다.

## 진동과 애니메이션은 Flutter로 되는가

결론은 된다. 진동은 플러그인으로, 애니메이션은 Flutter가 오히려 강한 쪽이다.

### 진동

| 필요한 것 | 방법 |
|---|---|
| 탭마다 짧은 톡 | Flutter 기본 `HapticFeedback.lightImpact()` 등. 플러그인도 필요 없다 |
| 세기와 패턴 조절 | `vibration` 같은 플러그인. 안드로이드는 세기 조절, 아이폰은 Core Haptics 패턴 |
| 플러그인으로 부족할 때 | 플랫폼 채널로 Swift, Kotlin 코드를 직접 부른다. 수십 줄 규모다 |
| 맥 | 진동이 없다. 포스터치 트랙패드 햅틱만 채널로 부를 수 있다 |

주의할 점: 초당 10회 넘게 연타하면 기기에 따라 진동이 뭉개진다. 빠르게 누를 땐 진동 간격을 조절하는
처리가 필요하고, 이건 실기기로 맞춰야 한다.

### 애니메이션

Flutter는 화면을 직접 그리기 때문에(Impeller 엔진) 플랫폼 기본 화면을 쓰는 앱보다 자유롭다.

- 눌림, 튕김, 숫자 올라가기: 기본 애니메이션과 스프링 물리로 된다.
- 연타할 때 튀는 입자, 화면 흔들림: `CustomPainter` 로 직접 그린다.
- 호일 같은 금속 광택, 구겨짐: 프래그먼트 셰이더(GLSL)로 그린다. 폰 기울기 센서와 엮어 반사광을 움직일 수 있다.
- 디자이너가 만든 애니메이션: Rive, Lottie 를 그대로 재생한다.

Flutter로 안 되는 것은 홈 화면 위젯이다. 위젯 화면 자체는 아이폰은 SwiftUI, 안드로이드는 Kotlin으로
따로 만들고, 데이터만 Flutter와 나눈다(초기 계획상 3단계 이후였으나, 현재 파일럿에 위젯 기본 구현이 들어갔고 실기기 확인이 남아 있다).

## 단계

### 0단계: 기술 확인 (먼저 한다)

Flutter로 정말 손맛이 나는지 작게 만들어 확인하고 넘어간다.

- 버튼 하나, 연타 시 진동, 입자 효과, 금속 광택 셰이더 하나.
- 안드로이드 실기기와 아이폰 실기기에서 초당 10회 연타로 끊김과 진동을 본다.
- 통과 기준: 120Hz 기기에서 끊김 없이, 진동이 탭과 어긋나지 않는다.
- 안 되면 진동만 플랫폼 채널로 바꾼다. 그래도 안 되면 그때 기술 선택을 다시 본다.

### 1단계: 내 기록 파일럿

- 기분 고르기, 연타, 날짜별 행복과 슬픔 기록, 기록 화면.
- 기기 안 저장. 계정 없음, 서버 없음.
- 기록 계산은 테스트로 고정한다.

### 2단계: 디자인

- 쿠킹호일 디자인 요소를 입힌다. 무엇을 가져올지는 보류 중이다.

### 3단계: 함께 보는 지도

- 서버, 익명 계정, 기분 업로드.
- 위치는 정확한 좌표를 올리지 않는다. 동네 크기 격자로 뭉개서 올리고, 지도에는 격자별 합계만 그린다.
- 한 격자에 사람이 일정 수 미만이면 표시하지 않는다. 한 명뿐인 동네에서 누구 기분인지 드러나기 때문이다.
- 지도는 `flutter_map`(OSM) 또는 `google_maps_flutter`.

### 4단계: 출시

- 플레이 스토어, 앱 스토어. 위치 권한 설명 문구와 개인정보 처리방침이 필요하다.
- 맥은 파일럿으로 같은 코드에서 낸다.
